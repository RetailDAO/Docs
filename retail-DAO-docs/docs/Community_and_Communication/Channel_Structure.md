# Discord Channels Configuration: :gear:


This is the entry point for new visitors or participants and these channels are public (not token-gated).


- **Start Here** (public)
- **Collabland-join** (public)
- **Support-contact** (public)

## Information

- **Announcements** (Public)
- **Leaderboard** (Public)
- **FAQ & Rules** (Public)
- **Official Links** (Public)

## Earn Tokens (channels with token earning programs or specific token compensated roles)

- **Hiring** (token gated)
- **Engage** (token gated)

## Alpha Zone (default: token gated)

- **General Chat**
- **Alpha Forum**
- **VIP Chat** (New - token gated for Tier 3 VIPMembers)  
- **KOLs-only** (non-token gated, but private)
- **Hall of Fame** (showcasing token gated content from the server; public)

## Governance Zone (default: token gated)

- **Gov Forum** (New - token gated)

- **Gov Proposals** (New - Public)


Only Snapshot bot and moderator post proposal links here, with a proposal title. Members cannot post, nor comment in this channel (discussions need to take place in the Governance Forum).


## Teams Zone (fully token gated, fully private, invite only)

- **Ideas for Improvement** (public)
- **Content Team**
- **Ambassador Program**
- **Partnerships Team**
- **Operations Team**
- **Product Team**
- **Marketing Team**
- **Treasury Team** 

## Admin Panel (token gated, private channels, invite only)


This Zone is for admin/moderation purposes and will have a few extra channels too.


- **Voice Channels** (fully token gated)
- **General** (token gated)
